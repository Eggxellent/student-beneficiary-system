# Student Beneficiary System

Full-stack application for managing student beneficiary records.

## Stack

- **Frontend:** React
- **Backend:** Node.js + Express
- **Database:** PostgreSQL

## Project Structure

```
student-beneficiary-system/
├── backend/     # Express API server
└── frontend/    # React client app
```

## Getting Started

### Backend

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm start
```
